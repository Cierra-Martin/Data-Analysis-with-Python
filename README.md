# Data Analysis with Python

Projects completed as part of freeCodeCamp's Data Analysis with Python certification.

## Projects

- **Demographic Data Analyzer** — analyzed U.S. census data to answer demographic questions using Pandas
- **Mean-Variance-Standard Deviation Calculator** — built a function to calculate statistical measures on a 3x3 matrix using NumPy
- **Medical Data Visualizer** — visualized and analyzed medical examination data to explore health metric relationships
- **Page View Time Series** — visualized time series data and identified trends/seasonality in page view counts
- **Sea Level Predictor** — used linear regression to predict future sea level rise based on historical data

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn
